## D1. Канал владельца: Telegram-бот плюс правило провенанса

Рекомендация: принять W2 как описано (PROMPT.md W2; DESIGN.md раздел 3).

Обоснование: владелец уже выбрал Telegram-бот плюс внешний heartbeat в консультационной сессии
`claude-ad7cc4169e888ea8` (README.md). Бот не открывает портов и не поднимает localhost-сервер.
Правило провенанса сохраняет силу AGENTS.md раздел 2: каждый ответ владельца пишется в
`.ai/runtime/owner-inbox/<id>.json` и транскрибируется в журнал сессии строкой
`Owner via Telegram, <ISO time>, message <id>: <text>`; утверждение блока решения таким путём —
прямое подтверждение владельца, транскрибированное с провенансом. Голос: локальный whisper.cpp,
эхо «Understood: ...» с кнопкой [Correct]; директивой становится только подтверждённая
расшифровка. Опасные действия — двухшаговое подтверждение.

Последствия: токен только в env `TELEGRAM_BOT_TOKEN`; принимается только чат из
`TELEGRAM_OWNER_CHAT`, остальные отправители игнорируются и логируются; появляется локальная
зависимость whisper.cpp и внешний аккаунт heartbeat (healthchecks.io или аналог, пинг раз в
5 минут; тишина — алерт по Telegram и почте); владелец выбирает место скрипта
`protocol-notify.cjs` (`.ai/bin/` или `ops/`); документируются настройки питания Windows (без
сна от сети переменного тока).

## D2. Роль консультанта (Opus 5.5) и правило независимости

Рекомендация: принять W3 (PROMPT.md W3; DESIGN.md раздел 2).

Обоснование: консультант диф-ограничен, событийный и read-only; никогда не сертифицирует
кандидат, которому он консультировал — review не сертификация (PROTO-DEC-0041 item 1;
PROTO-DEC-0047 item 1). Триггеры L2 поименованы: FAIL сертификации; противоречащие друг другу
отчёты; вопрос архитектуры, решения или безопасности; две неудачные рекавери L1. Где нужна
независимость, второе мнение — из другого семейства (GPT-5.6 Sol). При исчерпании маршрута
консультанта (недельный лимит claude уже 2026-09-27 отказывал каждому вызову — FACT,
`EVIDENCE.md`) — эскалация к владельцу или к Sol, никогда тихое понижение
(PROTO-DEC-0075 item 9).

Последствия: возврат из L3 кнопкой ([back to L2 with my answer] / [decide at L1]); слоты
сертификаторов этим решением не задаются (см. D5); консультант ведётся в собственной сессии.

## D3. Лестница L0-L3 и её триггеры

Рекомендация: принять W3 (DESIGN.md раздел 2).

Обоснование: L0 — скриптовый супервизор, всегда включён, бесплатен: процессы проверяет скрипт,
а не нейронка (PROTO-DEC-0076 item 3). L1 — оператор (DeepSeek Flash), только событийный, без
поллинг-циклов; маршрут — `deepseek/deepseek-flash` через kilo с ключом владельца, effort max
(MODEL-ECONOMICS.md, Route notes 2026-09-27); у DeepSeek нет терминального клиента
(`.ai/docs/CLI-AGENTS.md` раздел 1). L2 — консультант (Opus 5.5) по триггерам D2. L3 — владелец
через Telegram (D1). Восстановление и живучесть — механические, по классам ошибок и бюджету
попыток (PROTO-DEC-0075 items 2-5, 11; PROTO-DEC-0051 item 4).

Последствия: состояние шага и жёсткий потолок — по PROTO-DEC-0075 item 5; пауза «столб» по
умолчанию 10 минут остаётся открытым вопросом OQ-3 (README.md, Transferred). W6 и W7 добавляются
только после разбора владельцем локального аудита инцидента с VPN-отчётом (PROMPT.md, финал
Workstreams).

## D4. Метрика стоимости резолвера и политика нулевой стоимости

Рекомендация: порядок резолвера остаётся — способность, совместимость, затем стоимость
(PROTO-DEC-0075 item 9); среди допустимых маршрутов нулевые первыми; на QUOTA_EXHAUSTED —
автоматический переход к следующему допустимому. Метрика — «стоимость на принятый результат,
включая переделки» (предложена как открытая в PROTO-DEC-0079; этим закрывается открытый вопрос
PKG-3 о метрике резолвера). В реестре маршрутов — поля стоимости по строкам (`costClass`:
included-subscription / free-tier / free-model / paid-token; цены in/out за 1M; лимит и окно
сброса; источник и дата).

Обоснование: подтверждённые строки показывают реальные $0-маршруты прямо сейчас: free-модели
Kilo, включая `kilo/kilo-auto/free` (работает при отрицательном балансе — эмпирика плюс страница
тарифов, COST-ZERO-ROUTES.md FACT); OpenRouter `:free` (50 запросов/сутки на нашем тире — FACT,
`EVIDENCE.md`; не каждый вариант 0/0 — верификатор REFUTED); Gemini API Free Tier (2.5-family и
gemma-4 — CONFIRMED, квоты численно не подтверждены). Подписочные CLI бесплатны только до
исчерпания квоты: copilot и claude 2026-09-27 отказывали каждому вызову (FACT, `EVIDENCE.md`).
Жёсткие пределы: без записи владельца не меняется слот сертификатора; без тихой замены сильной
модели слабой (PROTO-DEC-0075 item 9); авто-роутер-модели (`kilo/kilo-auto/free`,
`openrouter/free`) — только там, где идентичность модели не важна, с записью `modelRan`, никогда
для review или сертификации (PROMPT.md W4).

Последствия: для работы D4 нужны три премисы владельца (GAPS.md раздел 6): считать ли «включено
в подписку» премисой без account-level доказательства; разрешение (или запрет) на единичные
платные вызовы для чтения остатков и текстов ошибок; эталон баланса Kilo (~$0.03 в промпте против
`$-0.00` из `kilo profile`, GAPS.md раздел 4). Без них строки подписок остаются OPEN QUESTION.

## D5. Пара сертификаторов: MiMo-V2.6-Pro + GPT-5.6 Sol (замена Kimi K2.7 Code HighSpeed)

Рекомендация: для сертификации phase C (high-risk, PROTO-DEC-0038 item 1; PROTO-DEC-0041
items 1-2) назначить пару MiMo-V2.6-Pro и GPT-5.6 Sol; Kimi K2.7 Code HighSpeed (сертификатор по
PROTO-DEC-0086 item 1) заменяется — замена сертификатора требует записи владельца, как замена
MiMo-V2.6-Flash на MiMo-V2.6-Pro (PROMPT.md D5; пара уже названа для 2A в PROTO-DEC-0094 D.2).
Консультант не сертифицирует; максимум три раунда сертификации на замороженном кандидате
(PROTO-DEC-0047 item 5; PROMPT.md Phases).

Обоснование (PROMPT.md D5): в программе OwnerIdeas MiMo воспроизвёл дефекты PKG-2, которые Kimi
пропустил при сертификации в раундах 1 и 2; Sol верифицирован на stage 11; Kimi — API-only
(подписка Kimi Code отвечает 403 — FACT, `EVIDENCE.md`) и самый дорогой маршрут:
`kimi-k2.7-code-highspeed` $1.90/$8.00 за 1M (CONFIRMED у Vercel), `kimi-k3` $3/$15 (CONFIRMED у
OpenRouter и Vercel; PRICES-OFFICIAL.md).

Fallback, если владелец оставляет Kimi (PROMPT.md D5): выбирается API-вариант —
`kimi-k2.7-code-highspeed` $1.90/$8.00 или `kimi-k2.7-code` $0.95/$4.00. Цены Moonshot — FACT из
официального листинга, у верификатора UNVERIFIABLE; у Vercel highspeed — CONFIRMED,
`kimi-k2.7-code` — не проверялось (PRICES-OFFICIAL.md). Второй вариант — смена варианта, требует
отдельной записи владельца.

Последствия: цена MiMo-V2.6-Pro не подтверждена ни одной строкой (в реестрах есть только
`mimo-v2.5` $0.14/$0.28 и MiMo-V2.5-Pro, обе не проверены верификатором; PRICES-OFFICIAL.md) —
остаётся OPEN QUESTION до снятия цены с официального канала; free-канал MiMo завершён, MiMo идёт
через платный OpenRouter (запись в конфиге, официального источника нет — COST-ZERO-ROUTES.md).
Независимость пары: оба сертификатора вне исполнения и контроля кандидата (PROTO-DEC-0041
item 1), из других семейств, чем исполнитель и оператор (PROMPT.md W3).
