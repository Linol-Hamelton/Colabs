# Промпт владельца: полное исследование нулевых по стоимости маршрутов (2026-09-27)

> Область: только УЖЕ имеющиеся сервисы владельца и только работа через CLI-клиентов.
> Цель: закрыть пробел в данных о стоимости; собрать нулевые/квази-нулевые маршруты и
> официальные цены для всех используемых моделей. Промпт подготовлен оператором по заказу
> владельца, не запущен.

## Роль и результат

Ты — оператор исследовательской рамки. Ты распределяешь, собираешь, сводишь и отчитываешься;
сам ничего не сертифицируешь. Результат: (1) реестр нулевых по стоимости маршрутов, (2) свежий
реестр официальных цен по всем используемым моделям/сервисам, (3) список «бесплатно, пока не
кончится баланс», (4) явные пробелы и неопределённости. Всё — с адресом источника и датой.

## Границы (жёсткие)

- Только сервисы, которые у нас уже есть: подписки и ключи, перечисленные ниже. Новых сервисов
  и ключей не заводить.
- Только модели, достижимые через CLI (claude, codex, agy, vibe, kimi, copilot, kilo, mimo).
  Сервис без CLI не рассматривается.
- Сторонние обзоры/агрегаторы не использовать: только официальные каналы вендоров (страницы
  цен, документация подписок, доки CLI, `--help`, конфиги, официальные списки моделей).
- Никаких оценок и интерполяций: только объявленные цены и наблюдаемое поведение. Каждый факт:
  URL + дата снятия; для эмпирики — команда и её вывод.
- Ничего не менять в проде VPN и ядре; коммитов не делать (оператор коммитит по итогам).

## Вопросы на каждый сервис/CLI

1. **Список моделей**: какие модели реально выбираемы через CLI (точные id/алиасы), включая
   младшие и «включённые» (included) уровни. Источник: официальный список/доки/`--help`/конфиг.
2. **Нулевая стоимость**: какие из них $0 на марже по подписке, и за счёт какого механизма
   (included/0×-множитель, кредиты, rolling-квота, бесплатный тариф). Указать лимит и окно сброса.
3. **Поведение при исчерпании**: если квота/лимит достигнуты — работают ли базовые модели или CLI
   отказывает целиком. Эмпирическая мини-проверка на каждый CLI (один короткий вызов, дешёвый или
   $0; фиксировать точный текст ошибки).
4. **Тарифная модель**: что именно считается «премиум-запросом»/кредитом; сколько их в плане;
   когда сброс (день/неделя/месяц); что происходит с «включёнными» моделями после исчерпания.
5. **API-ключи**: по каждому ключу — полный доступный список моделей и официальные цены
   (in/out за 1M токенов), включая бесплатные варианты (например, `:free` у OpenRouter, если
   достижимы нашим ключом). Только официальные страницы цен.
6. **«Бесплатно, пока не кончится баланс»**: какие модели на кредитных сервисах имеют $0 или
   минимальную цену, пока баланс > 0; как это проверяется; что будет при нуле баланса.
7. **Практика для оператора**: пригодно ли это для типовой задачи диспетчера (контексты
   десятки-сотни тысяч токенов, минуты работы, агентные шаги), и какие окна/лимиты ограничат.
