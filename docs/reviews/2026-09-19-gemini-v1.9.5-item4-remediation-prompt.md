## Fix 1 (A3-1) - record must not deadlock on the completion gate

Reproduction: with `Status: Completed` and a cited owner whose receipt is absent/stale, `record --owner <cited>` runs the validator, the validator runs `gate-check`, `gate-check` fails, and the receipt can never be refreshed (`record` exit 1, re-record exit 1, `verify` "records a failing check").

Required change:

1. In `.ai/bin/protocol-handoff.cjs`, wherever the `record` command spawns the validator check, pass an environment variable, e.g. `PROTOCOL_SKIP_GATE=1`, in `spawnSync`'s `env` (merge with `process.env`).
2. In `validate-protocol.ps1`, inside the `role: source` gate-check block, skip the `gate-check` invocation when `$env:PROTOCOL_SKIP_GATE -eq '1'` and print a short `[PASS] gate-check skipped during evidence recording` line. Every other check must run unchanged; the standalone validator still enforces the gate.
3. Regression test (extend `tests/gate.test.cjs`): Completed fixture, owner journal naming the review but with no Evidence yet -> `record --owner <owner> --quick` exits 0 and `verify --owner <owner> --deep` exits 0; after that, a standalone `gate-check` exits 0 (receipt fresh). Also assert that mutating a tracked file afterwards makes both `verify` and `gate-check` fail again.
4. Do not suppress the gate anywhere else; do not weaken the check itself.

## Fix 2 (A3-2) - missing or invalid Date must fail

Reproduction: a review without `Date` (and without `Mode`/`Receipt-Owner`) is classified as legacy and `gate-check` exits 0 with warnings even when no journal mentions it.

Required change:

1. In `gateCheck`, compute `isLegacy` only when a valid `Date` field is present and its ISO date is `<= 2026-09-19`. A missing or unparseable `Date` in the cited independent review is an immediate failure: "independent review <path> is missing or has an invalid Date". Keep the existing message for a future date missing `Mode`.
2. Tests: missing `Date` -> exit 1; malformed `Date` (for example `not-a-date`) -> exit 1; genuine legacy `Date: 2026-09-19` without fields and with a fresh receipt -> exit 0 with WARN (existing test 3b must stay green).
3. Update the PROTOCOL.md bullet: legacy cutoff applies only to a present `Date <= 2026-09-19`; a missing or invalid `Date` fails.
