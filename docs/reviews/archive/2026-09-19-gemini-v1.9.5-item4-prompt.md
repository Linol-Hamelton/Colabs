### 2. New subcommand `node .ai/bin/protocol-handoff.cjs gate-check [--root <path>]`

Algorithm:

1. Parse `.ai/TASK.md`. If the status is not `Completed`, print `not applicable: task status is <status>` and exit 0.
2. If `Completed`: parse the `## Completion gate` section; require both fields (`Adversarial review prompt`, `Independent review`); each file must exist under `docs/reviews/` and be non-empty. These duplicate today's validator checks intentionally, so `gate-check` is self-contained.
3. For the independent review, parse the header:
   - `Verdict:` must be `PASS` or `RECOMMENDATION`; anything else (including `CONDITIONAL PASS`) fails.
   - `Mode:` - reviews with a `Date:` after `2026-09-19` require `CERTIFYING`; `ADVISORY` or missing fails. Reviews dated `2026-09-19` or earlier are legacy: a missing field is a WARN, execution continues.
   - `Receipt-Owner:` (`Session:` accepted as fallback) - required for new reviews, WARN for legacy.
   - `Receipt:` is optional and may be empty or absent; when present it is informational only (do not verify its contents beyond being a non-empty string).
4. Receipt binding (the core rule):
   - Resolve `.ai/worklog/<owner>.md`; missing journal fails.
   - Scan every dated section of that journal. A section **satisfies the binding** only when both hold:
     a. the section body mentions the cited review path (normalize `\` to `/`; match the path string, e.g. `docs/reviews/<file>.md`), and
     b. the section's Evidence passes the `checkOwnerReceipt(..., { deep: true })` checks against the current tree (digest, format/auth, entry hash, parent chain, archived chain, recorded check failures).
   - Distinguish failure reasons in the output: stale receipt, review path not mentioned, no Evidence at all, owner mismatch.
   - `Mode: ADVISORY` or a `Transcribed by:` review can never satisfy the independent slot; fail with that explicit reason. Advisory reviews may still be listed elsewhere in TASK; only the independent review field is checked.
5. Exit 0 on pass, 1 on failure; human-readable lines; no writes anywhere.
